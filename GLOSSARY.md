# Sol glossary

| English | Ukrainian | Meaning in Sol |
| --- | --- | --- |
| Space | Простір | A workspace with its own tab groups and appearance. |
| Favorites | Улюблене | The grid of frequently used tabs above the Space name. |
| Pinned | Закріплені | Tabs and folders kept in the current Space. |
| Today | Сьогодні | The current Space's unpinned tabs. |
| Archive | Архів | Closed tabs that can be restored. |
| New tab | Нова вкладка | Opens the command bar to create a tab. |

Keep product names such as Sol and keyboard key names such as Esc as written. Translate the surrounding instruction as a complete sentence so key names and placeholders can move naturally.
